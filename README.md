# Alim — Portfolio Website

A professional, responsive portfolio website for GitHub Pages.

## Files
- `index.html` — main portfolio page
- `style.css` — design and responsive styles
- `script.js` — mobile menu and footer year
- `assets/profile.jpg` — supplied profile photo

## Publish on GitHub Pages
1. Create a new GitHub repository (for example: `alim-portfolio`).
2. Upload all files and folders from this ZIP.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the live website URL.

No build tools or server are required — it is a static HTML/CSS/JS website.
